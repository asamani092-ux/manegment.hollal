# البند 1 — سلسلة واحدة لكل نوع طلب

النتيجة: لكل نوع طلب صف واحد في `approval_chains`. الشرائح القديمة تبقى في `approval_rules` ولا تُقرأ عند الاعتماد. الطلبات السارية تكمل على اللقطة، والطلب الجديد يقرأ السلسلة الحالية.

## السلاسل المشتقة من البيانات التجريبية

| النوع | الخطوات |
| --- | --- |
| صرف | المدير المباشر دائمًا ← المالية إذا بلغ 1000.01 ← الإدارة التنفيذية إذا بلغ 10000.01 |
| عهدة | مثل الصرف |
| عقد | المالية دائمًا ← الإدارة التنفيذية إذا بلغ 10000.01 |
| عرض سعر، إجازة، عمل إضافي، استئذان، إنابة | المدير المباشر ← الإدارة التنفيذية ← المالية، بلا شرط |

تحويل الأدوار: دور المالية إلى نورة المالية، ودور الإدارة التنفيذية إلى سارة المديرة التنفيذية. لا مبالغ ثابتة في الكود؛ الأرقام أعلاه ناتجة عن الشرائح القديمة ويمكن تغييرها من الشاشة.

## الملفات

- ترحيل `2026_10_05_120000_create_approval_chains.php`
