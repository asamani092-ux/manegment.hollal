# البند 0 — بناء الصورة محليًا

النتيجة: بناء الصورة نجح. المعرّف `b619f0622b09` والوسم `hollal-app:local` والحجم 877 ميجابايت. الأمر: `docker build -f Dockerfile -t hollal-app:local --build-arg SOURCE_COMMIT=f300723 .` من مجلد `hollal-platform` وملف `docker-compose.coolify.yml`. خرج البناء `EXIT:0`.

ما فُحص في الالتزامين `12365b1` و`4dc85b2` وما بعدهما:

- صورة واحدة `hollal-app:local`. خدمة التطبيق تبنيها، والطابور والمجدول يستخدمانها مع `pull_policy: never` بلا مفتاح بناء ثانٍ. هذا يمنع تعليق بناء الإضافات ثلاث مرات.
- تثبيت الإضافات بالأمر الرسمي `docker-php-ext-install` وليس `install-php-extensions`.
- لا فحص صحة على خدمة التطبيق. فحص صحة قاعدة البيانات فقط.
- نقطة الدخول تُخرج 1 إذا غاب مفتاح التطبيق أو لم تجهز القاعدة خلال ثلاث دقائق. فشل الترحيل لا يوقف المستمعين.
- النسخ من صورة `composer:2` خطوة واحدة وليست بناءً متعدد المراحل للتطبيق.

عند فحص الرابط التجريبي أثناء هذا البند أعادت العلامة JSON وليست نصًا قديمًا: `marker=hr-fix-9` والالتزام `f300723` وحالة الترحيل `ok` والعدد المعلق `0`. الدليل الذي ذكر النص `hr-ext-official` لا يطابق ما ظهر وقت الفحص.
