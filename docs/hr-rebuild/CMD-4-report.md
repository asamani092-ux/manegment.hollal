# تقرير CMD-4 — المخالفات

لم يُجلب النص الرسمي لجدول الوزارة، فزُرع بند مسودة واحد «نموذج — للاختبار» دون اختراع جزاءات.

## القبول المغطى

- نافذة 180 يوماً تغيّر رقم التكرار (اختبار 20 يونيو يبقى داخل النافذة، و2 يوليو يخرج).
- القرار يُرفض قبل الإفادة إذا لم تنتهِ المهلة.

## انحراف

واجهة المخالفات الكاملة وجدول الوزارة الرسمي مؤجلان حتى يوفّر المالك الملف. السؤال المفتوح: أرسل جدول المخالفات المعتمد.

النسخة الاحتياطية: مسؤولية المالك عبر كولفاي
