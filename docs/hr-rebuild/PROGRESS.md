# تقدم إعادة بناء الموارد البشرية

- أزيلت عبارة «التقييم الربعي» من الواجهة والقائمة
- تسويات المسير المعتمدة تدخل في توليد المسير، والمقترحة تمنع الإرسال للمالية
- شاشة المخالفات: مقترحة / إفادة / قرار / الكل، مع استبعاد
- مساحتي تعرض ملف الموظف
- لم يُستكمل: جدول الوزارة الرسمي، والشجرة الرسومية الكاملة، وتفكيك كل تبويب لملف مستقل
- النسخة الاحتياطية: مسؤولية المالك عبر كولفاي
