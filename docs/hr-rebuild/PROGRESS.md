# تقدم إعادة بناء الموارد البشرية

- مساحتي تعرض نفس ملف الموظف مع الإبقاء على طلب الإجازة والمسير
- ملف الموظف: تحويل المفاتيح القديمة إلى التبويبات الجديدة
- الشجرة: عرض متداخل فوق الجدول، مع الإدارة العليا والتعيين بدور افتراضي
- التهيئة: تُولَّد عند إضافة موظف إن وُجدت القائمة
- النشر الأخير الذي أثبت أرصدة الإجازة: العلامة `leave-balances-d470f80`
- النسخة الاحتياطية: مسؤولية المالك عبر كولفاي
