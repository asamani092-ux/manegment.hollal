# تقدم إعادة بناء الموارد البشرية

- وثائق الموظف: رفع بانتظار المراجعة، اعتماد يستبدل السابق، ورفض بسبب
- التهيئة: تم / تحويل إلى مهمة / إغلاق، ورقم البصمة يُغلق الخطوة تلقائياً
- المدير الفعلي: الاستثناء اليدوي ثم المدير المباشر
- زر جمع الإدارات تحت الإدارة العليا
- ما بقي من الوثيقة: جدول الوزارة الرسمي، وجهاز البصمة، والشجرة الرسومية بالمكتبة الخارجية وتصديرها
- النسخة الاحتياطية: مسؤولية المالك عبر كولفاي
