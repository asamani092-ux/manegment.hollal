## المطلوب تصميمه في Figma (حسب الأولوية)

### أولوية 1 — أساس كل الشاشات

1. **الزر Button**
   - أنواع: أساسي (ممتلئ) · إطار Outline · شفاف Ghost · خطر Danger · ثانوي Secondary
   - أحجام: صغير · متوسط · كبير
   - حالات: عادي · مرور · ضغط · تعطيل · تحميل (spinner)
   - مع أيقونة يمين/يسار النص

2. **الشارة Badge**
   - أنواع: محايد · معلومات · نجاح · تحذير · خطر · باهت
   - اختياري: نقطة · عدد رقمي

3. **زر بعدد Count Button**
   - نفس شكل Outline الصغير
   - نص + `(3)` أو شارة عدد بجانبه
   - يُستخدم لتوحيد «المهام» و«الموانع» في الجداول

4. **التنبيه Alert**
   - معلومات · نجاح · تحذير · خطر
   - عنوان اختياري + نص + إغلاق

5. **حقول النموذج**
   - Input · Select · Textarea · Checkbox
   - حالات: عادي · تركيز · خطأ · تعطيل
   - تسمية فوق الحقل + رسالة خطأ + تلميح تحت الحقل

6. **مجموعة حقل Form Group**
   - تسمية + حقل + خطأ + تلميح توضيحي

---

### أولوية 2 — نوافذ ولوحات (مهمة جداً لتجربة الاستخدام)

7. **نافذة Dialog / Modal**
   - أحجام: صغير · متوسط · كبير
   - أجزاء: عنوان · محتوى قابل للتمرير · تذييل أزرار
   - خلفية معتمة · إغلاق (×) · إغلاق بالنقر خارجاً
   - فوق الشريط العلوي والقوائم (طبقة عالية)

8. **نافذة تأكيد Confirm**
   - عنوان + جملة توضيح + زر إلغاء + زر تأكيد
   - نسختان: تأكيد عادي · تأكيد خطير (أحمر) — مثال: حذف، تجميد حساب

9. **لوحة عائمة Drawer / Panel**
   - لوحة وسط أو من الجانب للتفاصيل
   - عنوان + تبويبات داخلية اختيارية + قائمة بطاقات + زر إغلاق
   - أمثلة المحتوى: مهام الإنهاء · الموانع · أعضاء لجنة · بطاقة وظيفة

10. **التبويبات Tabs**
    - أفقي · حالة نشط/غير نشط
    - اختياري: عدد بجانب الاسم `(4)`
    - داخل الصفحة وداخل اللوحة العائمة

11. **صف الفلاتر Filters Row**
    - بحث + قوائم منسدلة + تاريخ في صف واحد متجاوب
    - زر «مسح الفلاتر» اختياري

---

### أولوية 3 — قوائم وجداول وبطاقات

12. **البطاقة Card**
    - عنوان اختياري · محتوى · تذييل
    - حالات: عادي · مرور · محدد · مكتمل (خلفية خضراء خفيفة للمهام المكتملة)

13. **عنصر قائمة List Item**
    - أيقونة/شارة حالة + عنوان + وصف قصير + رابط إجراء

14. **شريط أدوات Toolbar**
    - صف أزرار متجاورة بمحاذاة RTL

15. **قسم Section**
    - عنوان قسم + وصف قصير + محتوى

16. **مؤشر Stat**
    - رقم كبير + تسمية — للوحة الرئيسية

17. **شريط تقدّم Progress**
    - نسبة أو كسر `1/4` مع شريط مرئي

18. **رابط نصي Link**
    - داخل الجداول والبطاقات

19. **شريحة ملف File Chip**
    - اسم ملف عربي مقروء + أيقونة نوع + تنزيل + حذف

20. **صورة رمزية Avatar**
    - أحرف الاسم أو صورة دائرية صغيرة

21. **حالة فارغة Empty State**
    - أيقونة + رسالة + إجراء اختياري

22. **شارة حالة Status Badge**
    - حالات عربية جاهزة: نشط · مسودة · منشور · مؤرشف · مكتمل · قيد الإنهاء · مجمّد …

23. **أيقونات إجراء Action Icons**
    - عرض · تعديل · حذف (مع تأكيد للخطر)

### أولوية 4 — هيكل التطبيق

24. **الشريط الجانبي Sidebar**
    - مجموعة قابلة للطي · عنصر قائمة · نشط · بحث «لا توجد أداة…»

25. **الشريط العلوي Navbar**
    - حساب · إشعارات (جرس) · مساحة Toast أعلى الوسط

26. **طي المحتوى Collapsible**
    - مثل «يحتاج تدخلك» في الرئيسية (مطوي افتراضياً)

27. **هيكل تحميل Skeleton**
    - أثناء انتظار الصفحة

28. **ترقيم الصفحات Pagination**
    - سابق / تالي + أرقام

## قواعد تصميم للمنصة

1. الواجهة عربية RTL؛ لا تُعكس الأيقونات ذات الاتجاه المعنوي إلا عند الحاجة.
2. البطاقات ليست زخرفة: تُستخدم فقط كحاوية لتفاعل أو قائمة.
3. تجنّب تكديس الشارات والحبوب (pills) في نفس الصف دون حاجة.
4. التباين كافٍ للنصوص على الخلفيات الفاتحة.
5. النوافذ العائمة فوق كل شيء؛ لا تُقطع بجداول أو شريط جانبي.
6. توحيد الأزرار المتشابهة (نفس الحجم والحشو والزوايا) — خصوصاً أزرار المتابعة في الجداول.
7. الحالات تُقرأ باللون + النص العربي معاً.
