# تصميم التقييم الربعي الإلزامي — دراسة فقط

> الحالة: **دراسة وتصميم — لم يُنفَّذ بعد**  
> التاريخ: 2026-08-28  
> السياق: HR Round 2 — شاشة التقييم الحالية تبقى كما هي؛ هذا المستند يصف الدورة الإلزامية الربعية.

## الهدف

إلزام تقييم ربع سنوي لكل العاملين عبر مسار: **الموارد البشرية → المديرون → إكمال التقييمات**، مع تتبّع حالات عدم الإكمال.

## الدورة المقترحة

| المرحلة | الفاعل | الوصف |
|---|---|---|
| 1. فتح الربع | HR | إنشاء «دورة تقييم» للربع (Q1–Q4 + سنة) لكل موظف نشط |
| 2. إسناد | HR | ربط كل موظف بمقيّم (المدير المباشر افتراضياً، قابل للتعديل) |
| 3. تذكير | النظام | إشعار للمديرين عند الفتح + تذكيرات قبل الإغلاق |
| 4. التقييم | المديرون | تعبئة بنود المسؤوليات / النموذج الجماعي الحالي |
| 5. إغلاق | HR | قفل الدورة · أرشفة · تقرير نسبة الإكمال |

## ربط الشاشة الحالية

- إعادة استخدام `PeriodicEvaluation` + `EvaluationsIndex` (بحث ذكي + جماعي من Round 1).
- إضافة كيان/جدول مقترح لاحقاً: `evaluation_cycles` (`year`, `quarter`, `opens_at`, `closes_at`, `status`).
- صف لكل موظف في الدورة: `evaluation_cycle_assignments` (`employee_id`, `evaluator_id`, `evaluation_id` nullable, `status`).

## حالات عدم الإكمال

| الحالة | السلوك |
|---|---|
| لم يبدأ | يظهر في لوحة HR ومتابعة المدير |
| مسودة | يُحسب غير مكتمل حتى النشر |
| متأخر بعد الإغلاق | تقرير استثناء · لا يُفتح تلقائياً إلا بقرار HR |
| معفى | حالات نادرة (مجمّد / منتهي علاقة) تُستثنى عند الفتح |

## تذكيرات

- يوم الفتح: إشعار لكل مقيّم بعدد التقييمات المطلوبة.
- منتصف الدورة: تذكير لمن لم يُكمل.
- قبل الإغلاق بـ 3 أيام: تذكير عاجل + ملخص لـ HR.

## خارج النطاق (هذه الجولة)

- لا migrations ولا واجهة دورة ربعية في Round 2.
- التنفيذ الكامل في جولة لاحقة بعد اعتماد التصميم.

## تعقيد متوقع عند التنفيذ

- فتح دورة لكل العاملين: زمن O(n) | مساحة O(n).
- تقارير الإكمال: O(n) مجمّعة بـ SQL.
