# برنامج المراجعة الشاملة — منصة حلّل

## الهدف

مراجعة منهجية لكل أدوات المنصة تبويباً تبويباً، مع تقييم مستقل لكل تبويب، قبل الاعتماد النهائي للنشر.

## المنهجية (Agile)

| مفهوم Agile | التطبيق في المراجعة |
|---|---|
| Epic | تبويب رئيسي (11 تبويباً) |
| Sprint | أداة واحدة أو مجموعة أدوات مترابطة داخل التبويب |
| Story | بند فحص واحد (checks) أو خطوة في دورة الحياة |
| Definition of Done | كل أدوات التبويب = «يعتمد» في `/uat/tools` |

## ترتيب المراجعة (11 تبويباً)

1. **الموارد البشرية** — أساسيات + دليل العاملين + رواتب + حضور + إجازات
2. **إسناد** — مهام · فريق · تقويم · أحمال
3. **الاجتماعات** — جدولة · محضر · قرارات
4. **المستندات** — مستودع · قوالب · نسخ · سياسات
5. **التقارير** — مركز · أسبوعي · سجل نشاط
6. **الأقسام والهيكلة** — أقسام · هيكل · وظائف · لجان
7. **الأدوار والصلاحيات** — أدوار · صلاحيات · استثناءات
8. **إعدادات المنصة** — عامة · مالية · SMTP
9. **المالية** — صرف · عهد · محاسبة · تقارير
10. **الشراكات** — جهات · تشخيص · رحلة · بوابة
11. **المشاريع** — محفظة · برامج · تنفيذ · قياس

## قاعدة الانتقال (Gate)

- لا يُفتح التبويب N+1 حتى تُعلَّم **كل** أدوات التبويب N «يعتمد».
- «يحتاج تحسين» أو «غير مجرّب» يمنع الانتقال.
- التقييم محفوظ على السيرفر عبر `/uat/tools`.

## محاور الفحص لكل أداة

1. **الوظيفة الأساسية** — CRUD والعمليات الرئيسية
2. **الأدوات الداخلية** — تبويبات فرعية وصفحات مرتبطة
3. **تدفق البيانات** — من الإدخال إلى التخزين والعرض
4. **التكامل** — ربط مع أدوات أخرى (مهام، مالية، HR...)
5. **دورة الحياة الكاملة** — من الإنشاء إلى الأرشفة/الإغلاق
6. **التوثيق** — تسجيل كل خطوة في سجل التبويب

## الأدوات

| الأداة | المسار | الغرض |
|---|---|---|
| قائمة UAT | `/uat/tools` | تقييم كل أداة + بوابة التبويبات |
| لوحة التقدّم | `docs/plans/review/00-BOARD.md` | حالة كل تبويب وأداة |
| سجل التبويب | `docs/plans/review/NN-*.md` | سجل التجربة اليدوية التفصيلي |

## الأدوار

| الدور | المسؤولية |
|---|---|
| المستخدم (عبدالله) | التجربة اليدوية · الاعتماد · «يعتمد» في UAT |
| الوكيل (Cursor) | إصلاح الأخطاء · تحديث الاختبارات · توثيق الإصلاحات |

## سير العمل لكل تبويب

```
فتح سجل التبويب → Sprint لكل أداة → تجربة يدوية → تقييم UAT
    → إصلاح (إن لزم) → إعادة تجربة → اعتماد التبويب → التبويب التالي
```

## Big O

- **التقييم:** O(n) حيث n = عدد الأدوات (~70)
- **الحفظ:** O(n) حالة حالية + O(k·n) لقطات تاريخية

4. لا تنتقل للتبويب 2 حتى يكتمل التبويب 1 بالكامل
